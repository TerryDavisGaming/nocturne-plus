nocturne+ 2.9.1 (formerly nocturne but better, and nocturne flat scroll)
windows x64 | steam nocturne 1.0.2 | tested steam build 25684815
works with bepinex 6 (bundled) or melonloader 0.7.3 and newer (not bundled)

install
1. install nocturne through steam, then close the game.
2. extract this entire zip to a folder. do not run it from inside the zip.
3. double-click install.cmd. it finds the steam game folder automatically.
   if asked for a folder, use steam > nocturne > manage > browse local files
   and paste the folder containing nocturne.exe.
4. start nocturne normally through steam. the first launch can take longer
   while the loader prepares files; internet access may be needed.
5. open options > gameplay and set:
   note scrolling   - default, 2d downscroll, or 2d upscroll
   receptor height  - -10% to +30%; moves the receptors in from their edge
                      of the screen in both 2d modes (0% = original spot)
   note size        - 50% to 150%; notes and receptors in both 2d modes
   lane spacing     - 60% to 150%; how far apart the 2d lanes are
   note skin        - default bars, circles, or arrows
   note flares      - on or off; the burst when you hit or hold a note
                      (mine explosions always show)
   timing bar       - off or on; shows how early (rabbit) or late (turtle)
                      each hit was, next to the receptors
   timing bar position - 2d upscroll only: below enemy (under the receptors)
                      or above enemy (along the top of the screen)
   enemy attack opacity - 0% to 100%; how visible the enemy stays while it
                      attacks (100% = unchanged)
   infinite consumables (arcade) - off or on; in arcade battles, using a
                      consumable doesn't use it up. you still get one use
                      per battle, and battles that set your gear use
                      their own.
   all items (arcade gear) - off or on; the arcade gear page lists every
                      item in the game. a battle with an item your save
                      doesn't own saves no score.
   and at the bottom of the page:
   quick save & load - off or on; 12 quick save slots. hold the modifier
                      and press a slot's key to save the story there,
                      anywhere you can walk around (your own save slots
                      are never written over); the key on its own loads
                      that slot. good for practicing one part of a
                      chapter: save in the room before it, then walk in
   quick save modifier - ctrl to start with, or shift (shift is also the
                      game's run key)
   quick save slot  - left and right pick a slot (f1 to f11 to start
                      with, slot 12 has no key); click, then press its
                      new key
   the game's own note colors row gets a preview under it, with a red mine
   next to your notes so you can spot palettes that look like it, and the
   mod's own palette, akuma (see new in 2.7.0).
   custom note colors - under the note colors row: opens a page where you
                      make your own palettes, with any color on each lane.
                      they're listed in the note colors row after the
                      game's own.
6. in options > audio, under sound effects:
   hit sound        - off or on; a short tick when you hit a note
   hit sound volume - 5% to 100%; the game's sound effect volumes apply too
   miss sound       - on or off; the same setting as note miss sounds
   miss sound volume - 10% to 300%; 100% is the game's normal level
   main menu music  - on to start with; off silences the music on the
                      title screen and in the menus. battle and story
                      music play as always
7. in options > graphics, under corruption effects:
   performance      - normal (the game as it ships), optimized (the mod
                      does less work each frame; it looks and plays
                      exactly the same, minus the mod's own stalls) or
                      potato (for weak pcs: quicker fades, lighter bloom
                      and blur, a lower resolution on 4k screens, and the
                      game's lighter combat backgrounds and corruption
                      effects, which go back when you leave potato).
                      starts on normal.

which loader gets used
- melonloader 0.7.3 or newer installed and turned on: the mod goes into mods.
- no melonloader: the bundled bepinex loader is added where missing and the
  plugin goes into bepinex\plugins.
only one copy runs at a time. to switch loaders, run install.cmd again; it
disables the copy for the other loader. do not keep bepinex and melonloader
in the same game folder, because only one of them can start.

new in 2.9.1
- works with the game's 1.0.2 update (steam build 25684815). the update
  renamed a piece of the game's code that 2.9.0's custom battle dialogue
  hooked into by name, so battles played without their lines. 2.9.1 finds
  that piece by its shape, so a renumbering like that no longer matters.
  the installer and the fullscreen fix script only accept build 25684815
  now; a later steam update needs another compatibility check.
- main menu music, a new switch at the bottom of options > audio. turn it
  off and the music on the title screen and in the menus reached from it
  (the arcade, custom battles, the hub) fades out and stays off. battle
  and story music play as always. it starts on.
- on the hub, once its server has the matching update, a custom battle's
  listing picture shows as soon as the upload is done, with nothing for
  the hub's owner to approve first. the owner can still take a picture
  down afterwards.
- 2.9.1 was tested in the game on bepinex and on melonloader, on the
  updated game: custom battle dialogue, the main menu music switch, your
  own note colors, performance, the click-through fix and, on bepinex,
  quick save. package-verification.txt and the readme's "what was tested"
  (on github) have the details.

new in 2.9.0
- performance, a new row in options > graphics (see step 7). optimized
  cuts the mod's own work each frame and looks exactly the same as normal.
  potato is for weak pcs. it starts on normal.
- your own note colors. custom note colors, right under the note colors
  row, opens a page where you make up to 24 palettes with any color on
  each lane. you pick them in the note colors row like the game's own.
- quick save slots. quick save now has 12 slots of its own: hold ctrl and
  press f1 to f11 to save into a slot, and press the key on its own to
  load it. your own save slots are never written over. 2.8.0's f5 and f9
  keys aren't kept, so f5 now loads slot 5 and ctrl+f5 saves it.
- settings that changed by themselves. in 2.8.0 and before, a click in the
  chart editor or the battle creator could reach the options menu under
  it, so the game could go windowed or a volume could drop to 0%. that's
  fixed. closing the game during the latency test's video step no longer
  saves master volume as 0%, and leaving the latency test's song early
  puts the overworld sound effects back.
- the title: the mod's version now shows after the game's at the bottom
  right (in 2.8.0 it never showed), and the + is as tall as the logo's
  letters.
- on optimized and potato, the first battle of a session no longer stalls
  while the mod makes its note pictures.
- 2.9.0 was tested in the game on bepinex and on melonloader: the quick
  save slots, your own note colors, performance, the settings fix and the
  title. package-verification.txt and the readme's "what was tested" (on
  github) have the details.

new in 2.8.0
- a new name: nocturne+. its files are now nocturneplus.dll and
  nocturneplus.melonloader.dll. install.cmd turns the old
  nocturneflatscroll copy off (kept as a .disabled- file), and your
  settings, custom charts, custom battles, arcade gear and hub key carry
  over.
- quick save and quick load. switch them on at the bottom of options >
  gameplay. f5 saves the story anywhere you can walk around, into the
  game's autosave,
  and f9 goes back to your latest save. click a key row and press a key to
  change it. neither works on the title, in battles, cutscenes or
  dialogue, between screens, while paused, or in the arcade.
- the title screen reads nocturne+. 2.8.0 also meant to put "nocturne+
  2.8.0" and "by terrydavisgaming" under the game's version at the bottom
  right, but they never showed (fixed in 2.9.0).
- 2.8.0 came out without being tried in the game. 2.9.0's tests ran the
  new name and the title in the game, and quick save in its new form.

new in 2.7.0
- arcade gear. the arcade on the main menu has gear of its own. click
  the gear control in its title bar, press g, or press view on a
  controller, then pick each slot: story gear, empty, or an item your
  save owns. every battle there uses it unless a custom battle sets its
  own, and your story save never changes. with all items (arcade gear)
  on, you can pick any item, but a battle with one your save doesn't own
  saves no score and counts for no achievements.
- get custom battles. a new box on the title screen, above get
  soundtrack, opens the mod's online hub: browse, search, download and
  update custom battles and custom difficulties, and upload your own.
  the mod contacts the hub only while that page is open, and the online
  hub row on the custom charts page turns it off. every download is
  checked in full before it's installed, and nothing downloaded is run.
  uploads go live at once, the hub's owner can remove anything, and
  players can report entries. upload only what you made, with songs,
  pictures and videos only if you have the right to share them. there
  are no accounts: your first upload makes a hub key, and only that key
  can change or delete your uploads, so back it up (my uploads > back up
  key) and keep the file private. the hub is new and may be empty at
  first. it isn't run by or connected to the makers of nocturne.
- akuma. a note colors palette for controllers and guitar controllers.
  each lane takes the color of its pad button: a green, b red, x blue,
  y yellow, and the five-lane middle orange. on a keyboard the lanes are
  green, red, blue and yellow. its red is a crimson that doesn't look
  like a mine.
- the 2d armor badge. in the flat modes the enemy info boxes hid the
  enemy's armor badge. the badge and the enemy's statuses now move down
  below the boxes, and the enemy's meters move with them when the boxes
  would cover those too.

custom battles and the arcade button
the main menu gets an arcade button. it needs a save, like continue does,
and opens the arcade on your latest save. arcade scores go into that
save's .score file; your place in the story and your .sav files don't
change. custom battles are arcade-only battles with your own song and
charts, in the arcade's custom tab. make them in the battle creator:
custom charts on the main menu (or the custom charts tab in options) >
battle creator. its pages:
   info          - title, artist, charter, lore, and the arcade card's
                   picture: the card's slot is square, so fill it or show
                   the whole picture, crop it, pick crisp pixels, and see
                   an exact preview
   song          - an ogg, mp3, wav, flac, m4a or wma file
   charts        - six difficulties in 4 or 5 lanes, in the chart editor
   enemy         - a game enemy's fight with your own stats and info boxes
   art           - your own enemy art: image, gif, video or sprite sheet.
                   "turn into frames" makes a video a sprite sheet, so a
                   see-through colour works on it
   gear & level  - set gear or the player's own, and a set level or the
                   player's own. the player's own gear and level come
                   back after the battle, and the arcade shows what a
                   battle sets before you play it
   dialogue      - boss-style lines before the song, during it (over the
                   notes, or stopping the song), after a win and after a
                   loss.
                   speakers: karma (the player), game characters with
                   their faces, the narrator, or your own with pictures
a battle exports and imports as one .nbbbattle file, and deleting one
moves it to the recycle bin. a new battle can also start from an
osu!mania .osz (beta, not recommended). technical-notes.md describes
battle.json and the folder layout.

test in the chart editor
the chart editor's test button (f5 from the playhead, shift+f5 from the
start) plays the chart in a real battle and brings you back to the
editor. it works for custom battles and the game's songs when the editor
was opened from the title screen, and nothing is saved.

custom difficulties and chart editor
press custom charts on the main menu, or the custom charts tab in options:
   chart editor         - make or edit a chart for any song, with the song's
                          music playing, like osu!mania's editor: tools,
                          bookmarks, metronome, scroll speed changes, the
                          enemy's events, and keys you can change
   battle creator       - make or edit custom battles (see above)
   import custom chart  - opens a windows file picker; pick a .nbbchart
                          pack or an .sm file
   custom chart song    - the songs you have custom charts for
   custom difficulty    - off, or the chart to play instead of the game's
                          chart on that song, whatever difficulty you pick
   export custom charts - saves this song's or all songs' picked charts
                          into one .nbbchart file to share
   custom chart folder  - open it, or write the game's own charts into it
   online hub           - on or off; shows get custom battles on the title
the difficulty screen also gets a custom entry under zen. the song's enemy
events stay in, and custom chart scores are saved apart from the game's high
scores. boss fights split into parts (m1 to m3, gauntlets 1 to 4) can't take
custom charts yet. the readme explains the editor.

chapter badges
in arcade and high scores, a chapter button turns gold with two sparkles
once every encounter in it has its sparkles.

the flat modes include compact, vertical health/energy bars. alt, tab, and
the windows key don't start a battle at "press any key". any other key or a
controller button still does.

installations start on default, 0%, 100% size and spacing, default skin,
note flares on, timing bar off and below the enemy, enemy attack opacity
100%, infinite consumables and all items off, quick save & load off with
ctrl and f1 to f11, hit sound off at 80%, miss sound volume 100%, main
menu music on, and performance on normal. your selections are saved on
that pc. the title screen and the intro's logo card read "nocturne+", and
on the title's menu "nocturne+ 2.9.1 by terrydavisgaming" shows after the game's version
at the bottom right.

optional fullscreen flicker fix
if you have the flickering black bars, close nocturne and double-click
enable-fullscreen-fix.cmd. this applies the same directx 11 preference used
on the original pc. restore-fullscreen-fix.cmd reverses that change.
nocturne+ works independently of this fix.

remove
close nocturne, then run uninstall.cmd to disable this mod for both loaders.
run restore-fullscreen-fix.cmd too if you enabled the display fix.
uninstall keeps the loaders because other mods may use them. saves, scores,
other mods, custom charts, custom battles, the arcade gear, your hub key,
and saved scrolling preferences are left in place. if performance is on
potato, uninstall.cmd puts the game's combat backgrounds and corruption
effects settings back the way you had them.

if something does not work
- access denied: right-click the relevant .cmd and run as administrator.
- wrong build or unknown files: stop and use a package updated for your
  game version. the installer refuses unknown game files on purpose.
- an existing bepinex conflicts: this package needs bepinex il2cpp x64
  build 788. do not replace another mod setup without checking it first.
- melonloader too old: update it to 0.7.3 or newer, then run install.cmd.
- options rows missing: check bepinex\logoutput.log or
  melonloader\latest.log in the game folder. confirm the zip was fully
  extracted before running install.cmd. after a game update the loader
  rebuilds its copies of the game's code on the first start, which takes
  a minute or two; if that start was closed halfway, delete the
  bepinex\interop folder (melonloader: melonloader\il2cppassemblies) in
  the game folder and start the game again.
- a custom battle is missing from the arcade: open it in the battle
  creator to see its problems. the loader's log (bepinex\logoutput.log or
  melonloader\latest.log) says why the arcade skipped it.
- an mp3, flac, m4a or wma song won't play on a windows n edition: install
  the media feature pack, or convert the song to .ogg or .wav.
- get custom battles can't reach the hub: check the internet connection,
  then press f5. on a busy day the hub can be down until 00:00 utc.
  installed and delete still work.
- steam updates / verify integrity may remove the optional display patch.
  this package must be checked again after a game update.

share
send the original nocturne-plus-2.9.1-windows.zip to the other person
or device. they need their own installed copy of nocturne. the package
contains no game assets, game-generated assemblies, saves, or account data.
it does not support macos, linux, or steam deck through these installers.
